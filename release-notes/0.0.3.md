## en

- Adds `reltitle serve`, a line-protocol server for a long-lived host process: parse repeatedly from one start-up instead of rebuilding the dictionary on every call.
- `无修版` / `無修版` / `完全无修版` / `完全無修版` and `[Uncensored Ver.]` now emit `content_rating=UNCENSORED`, matching the value `无修正` and `Uncensored` already produced.
- Fixes the western name order `Tatsuki Fujimoto 17-26`: the title's `17-26` is no longer read as `S17E26`, so `01-08` parses as the collection's episode range.
