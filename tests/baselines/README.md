# Baselines

This folder stores pinned regression inputs and baseline outputs for v2, so future changes (config/code/ONNX integration) can be evaluated via diffs.

## Files

- `regression_set_v1.titles.txt`
  - Input titles (one title per line)
  - Source: `training/artifacts/analysis/slot_templates/regression_set_v1.jsonl` (field: `raw_title`)

- `baseline.v2.20260118.regression_set_v1.jsonl`
  - Authoritative v2 (rules) baseline output (JSONL, one result per line)
  - Generated by `cmd/parse_batch`

- `baseline.v2.20260122.regression_set_v1.jsonl`
  - Authoritative v2 baseline updated for current parser/tokenization
  - When evaluating override proposals that contain `title_start/title_end` token spans, the baseline used to generate proposals must match the parser version used to apply overrides; otherwise tokenization drift may cause spans to point at the wrong tokens (e.g. `]`), making results misleading.

- `baseline.v2+onnx.debug.20260118.regression_set_v1.jsonl`
  - v2 baseline with ONNX debug output enabled (`token_onnx`)
  - Feature-flagged by `TITLEPARSER_TOKEN_ONNX=1`

- `rss_titles_step2_v2_3000.titles.txt`
  - Input titles (one title per line)
  - Source: `training/resources/rss_titles_step2_v2_3000.txt`

- `baseline.v2.20260119.rss_titles_step2_v2_3000.jsonl`
  - Authoritative v2 baseline output for RSS titles (JSONL, one result per line)
  - Generated by `cmd/parse_batch`

- `archive/`
  - Historical baselines from intermediate iterations (kept for reference)

## Re-generate

From `title-parser/`:

```bash
# 1) Export raw titles from training regression set
python3 - <<'PY'
import json
src = '../training/artifacts/analysis/slot_templates/regression_set_v1.jsonl'
out = 'tests/baselines/regression_set_v1.titles.txt'
with open(src, 'r', encoding='utf-8') as f, open(out, 'w', encoding='utf-8') as w:
    for line in f:
        line = line.strip()
        if not line:
            continue
        obj = json.loads(line)
        rt = obj.get('raw_title', '')
        if not rt:
            continue
        w.write(rt.replace('\n', ' ').strip() + '\n')
PY

# 2) Run v2 batch parse
go run ./cmd/parse_batch -- -config configs \
  -in tests/baselines/regression_set_v1.titles.txt \
  -out tests/baselines/baseline.v2.20260118.regression_set_v1.jsonl

go run ./cmd/parse_batch -- -config configs \
  -in tests/baselines/regression_set_v1.titles.txt \
  -out tests/baselines/baseline.v2.20260122.regression_set_v1.jsonl

# 2b) Run v2 batch parse with ONNX debug output
TITLEPARSER_TOKEN_ONNX=1 go run ./cmd/parse_batch -- -config configs \
  -in tests/baselines/regression_set_v1.titles.txt \
  -out tests/baselines/baseline.v2+onnx.debug.20260118.regression_set_v1.jsonl

# 3) Print quick stats
go run ./cmd/regression_stats -- -in tests/baselines/baseline.v2.20260118.regression_set_v1.jsonl

# 4) Regression gate (golden diff)
go run ./cmd/regression_check -- -config configs \
  -base tests/baselines/baseline.v2.20260118.regression_set_v1.jsonl

go run ./cmd/regression_check -- -config configs \
  -base tests/baselines/baseline.v2.20260122.regression_set_v1.jsonl

# 5) Generate RSS titles baseline
python3 - <<'PY'
import pathlib
src = pathlib.Path('../training/resources/rss_titles_step2_v2_3000.txt')
dst = pathlib.Path('tests/baselines/rss_titles_step2_v2_3000.titles.txt')
lines = src.read_text(encoding='utf-8').splitlines()
out = []
for line in lines:
    s = line.strip()
    if not s:
        continue
    out.append(s.replace('\n', ' ').strip())
dst.write_text('\n'.join(out) + '\n', encoding='utf-8')
print(f'wrote {dst} lines={len(out)}')
PY

go run ./cmd/parse_batch -- -config configs \
  -in tests/baselines/rss_titles_step2_v2_3000.titles.txt \
  -out tests/baselines/baseline.v2.20260119.rss_titles_step2_v2_3000.jsonl

go run ./cmd/regression_stats -- -in tests/baselines/baseline.v2.20260119.rss_titles_step2_v2_3000.jsonl

go run ./cmd/regression_check -- -config configs \
  -base tests/baselines/baseline.v2.20260119.rss_titles_step2_v2_3000.jsonl
```
