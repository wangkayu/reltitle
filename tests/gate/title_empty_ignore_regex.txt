# Gate/eval-only ignore patterns for title-empty rows.
# This file does not affect parser runtime behavior.

# version-only noise sample, e.g. [v1]
(?i)^\[\s*v\d{1,2}\s*\]$

# pure episode list without any series title
(?i)^-\s*01\s+\[webrip\b.*\[(?:end|fin)\]$

# schedule/capture line, not a release title
^\[\d{4}-\d{2}-\d{2}\]\s+日曜アニメ劇場.*\.ts$

# non-target movie pack samples (legacy rip naming)
^\[Gundam G no Reconguista The Movie \d+\]\[BDRIP\]\[1080P\]\[X265_PCM_DTS-HDMA\]$

# non-target year-title sample in DBD batch style
^\[DBD-Raws\]\[\d{4}/\d{4}\]\[1080P\]\[BDRip\].*$

# legacy OVA descriptive line, non-standard mixed bracket form
^\[超次元ゲイム ネプテューヌ\].*Hyperdimension Neptunia.*$
